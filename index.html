Detecture · sub-semantic smoke test

Detecture on hard sub-semantic cases

A small set of test images, each built around one hard case for sub-semantic segmentation: lighting changes, gradual transitions, disconnected islands, scale, orientation, and scenes with many textures. For each image, Detecture decides by itself how many texture regions there are, writes a description of each one, and segments it from that description. It gets no region count and no annotation. Hover or tap a description to light up its region, or hover the overlay to find the description of a pixel.

Model: Detecture (Qwen3-VL-8B + SAM 3, checkpoint epoch 23), same count-free prompt for every image, one image at a time. The model sees each image resized to 1008×1008, and masks are mapped back to the original aspect ratio. Descriptions are the model's own generated text; region colours are numbered in the order the model wrote them. Grey = pixels the model left unassigned.
